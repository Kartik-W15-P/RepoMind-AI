# RepoMind AI

GitHub Repository Intelligence Assistant powered by Retrieval-Augmented Generation (RAG).

## Overview

RepoMind AI allows users to analyze a public GitHub repository and ask questions about its codebase, documentation, configuration, and project structure.

The system retrieves relevant repository content and uses an LLM to generate grounded answers with file references.

## Planned Features

- GitHub repository ingestion
- Repository file filtering
- Document chunking
- Embedding generation
- Vector search with ChromaDB
- Retrieval-Augmented Generation
- Source/file references
- Streamlit interface

## Tech Stack

- ChromaDB
